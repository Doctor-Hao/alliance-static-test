# Альянс

Адаптивная демонстрационная вёрстка главной страницы. HTML, стили и JavaScript работают без сборки. Контакты, проекты, отзывы и документы в демо условные. Карта использует статический набор объектов, а форма проверяет ввод локально.

Для просмотра запустите команду в этой папке и откройте [локальную страницу](http://127.0.0.1:8765/).

```sh
python -m http.server 8765 --bind 127.0.0.1
```
